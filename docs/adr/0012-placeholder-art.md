# 12. Placeholder art until human artists are hired

- **Status:** Accepted
- **Date:** November 2026 (recorded 2026-11-22)

## Context

The plan is a Kickstarter to pay a human visual designer, then a composer and voice actors. AI-generated art is controversial with exactly the audience the game is for.

## Decision

All visuals are deliberate placeholders: emoji and simple SVG drawn in code. No AI-generated images. A picture is swapped before then only when it is misleading (a ladder labelled "stairs", a silver coin labelled "gold"), because that affects learning.

## Consequences

The game looks rough, which is fine for a prototype. Notes on what each picture should be become the brief for the artist.
